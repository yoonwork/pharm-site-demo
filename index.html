HOW IT WORKS

상담이 누락되지 않는 구조

개발자 없이 운영하실 수 있게 만듭니다. 웹빌더와 맞춤 제작 중 고르실 수 있고 금액은 같아요. 누락 방지 기능이 모두 들어가는 맞춤 제작을 추천해요.

1원장님이 상담 신청

필수 항목·동의를 확인한 뒤에만 보내져요

2DB에 먼저 저장

저장이 끝나야 '접수 완료'를 보여 줘요. 실패하면 다시 보내라고 안내해요

3담당자에게 즉시 알림

문자 + 이메일 동시 발송. 카카오 알림톡은 채널·문구 승인 후 전환

4관리자에서 처리

새 접수 → 상담 중 → 완료, 엑셀(CSV) 받기, 알림 실패 시 재발송

A안 웹빌더(아임웹 등)B안 맞춤 제작 (이 데모 방식, 추천)
화면빌더 템플릿 기반으로 구성시안 그대로 자유롭게 구현, 모바일 최적화
상담 관리빌더가 지원하는 폼 기능 범위 안에서전용 관리자: 상태 관리, 검색, 엑셀, 상세·전화
알림빌더 기능 + 필요 시 외부 연동 추가문자·이메일(→알림톡) 직접 연동, 실패 기록·재발송
운영비빌더 요금제 월 이용료 + 도메인호스팅은 무료 한도 안에서 0원, 도메인(연 1~2만 원대), 문자·메일 건당 요금
내용 수정빌더 편집기로 직접 수정관리자에서 문구·사진·연혁·로고·링크 수정

어느 쪽이든 같은 금액 안에서 구축과 알림 연동을 맡아요. 모든 계정(도메인·서버·발송 대행사)은 귀사 명의로 만들고, 소스코드 일체(B안)를 넘겨 드려요. 문자 발송에는 발신번호 사전 등록이 필요해요.
